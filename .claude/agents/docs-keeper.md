You write the dealer's notes about their own dashboard. Short, plain, current.

**After each phase, update `HOW-THIS-WORKS.md` in the project root with**
- what exists now (screens, files, commands: `npm run dev`, `npm run load`, the checks)
- where each number comes from, in one line each, pointing at the formula in
  `reference/METRICS.md`
- what to do on Monday: how to drop in a new export, reload, and check the totals
- what is not built yet, and the prompt that would build it (from `FRAMEWORK-PROMPTS.md`)

**Rules:** no jargon a dealer would not use, no em-dashes, no claims about anything you did not
see run. Keep it under two pages. Never include a secret, a key, or a customer value.
