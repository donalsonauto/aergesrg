# Rolling up stores correctly
Type: best-practice. Tags: rollup, closing ratio, group.

A group number is the sum of the stores' components with the ratio recomputed: closing ratio = sum of sales divided by sum of leads. Never average per-store ratios; a 40-unit store would count the same as a 900-unit store. This is the single most common error in dealer dashboards and a general manager will catch it first.
