How much history

Twelve months is enough. Twenty-four makes year over year real. Thirty-six shows a source that died eighteen months ago.

Do not delay the export trying to get three years out of a stubborn CRM. Twelve months in hand beats three years in a ticket queue.

Ask your CRM for "lead source performance by month, with sales and gross"

Every system calls it something different. VinSolutions: Reports, Lead Source ROI, set the range to 12+ months and group by month. DealerSocket: Reports, Lead Source Analysis, export detail not summary. eLead: Analytics, Lead Source Performance, export to Excel. Reynolds or CDK: usually a custom report request.

Foureyes customers: ask Foureyes. Lead source, month, leads, sales and gross is what they track.

Could not get the export? Come anyway.

The toolkit ships a sample dataset: 36 months, 3 stores, 12 sources, with dead and declining sources planted in it. We run the first 80 minutes on it so every screen matches mine. You swap your own file in at the end.

Setup checklist

About 25 minutes. Finish it before you arrive; setup on the day costs the room twenty minutes.

  1. A Claude paid plan Required

    Pro ($20/month) is enough. Max, Team, Enterprise and Console also work. The free plan does not include Claude Code.

  2. Install Claude Code Required

    Open Terminal (press Cmd+Space, type "Terminal") and paste this.

    curl -fsSL https://claude.ai/install.sh | bash

    Open PowerShell (press Start, type "PowerShell"). You do not need to run it as Administrator.

    irm https://claude.ai/install.ps1 | iex

    If you get 'irm' is not recognized, you are in Command Prompt rather than PowerShell. Either open PowerShell instead, or use this:

    curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

    Then run claude once and follow the browser prompt to sign in.

  3. Install Git Required

    Run git --version. If it is missing, macOS offers to install it for you. Accept.

    git --version

    Install Git for Windows. Accept the defaults. Without it Claude Code uses PowerShell, and the session assumes Git Bash.

  4. Install Node.js Required

    Get the LTS build from nodejs.org and accept the defaults.

  5. A GitHub account Optional

    Only if you want to keep your dashboard in a repo later. Not needed for the session.

  6. A Vercel account Optional

    Only if you want a live URL at the end. Free, at vercel.com/signup. If you make one, log in once from the terminal after installing Node:

    npx vercel login

    The session ends with the dashboard running on your laptop either way.

  7. Download the toolkit

    Download it from bit.ly/OhMyDash2026, unzip it, and put the ohmydash folder on your Desktop. Then open a terminal in it:

    cd ~/Desktop/ohmydash
    cd $HOME\Desktop\ohmydash

  8. Put your CSV in that folder Optional

    Name it my-data.csv and drop it next to everything else. No export? Skip this; the sample data is in there.

Verify it worked

Run these three. If each prints a version, you are done.

claude --version # e.g. 2.1.211 (Claude Code) git --version # e.g. git version 2.43.0 node --version # e.g. v22.11.0

claude doctor runs a fuller check.

Is my data safe?

Data safety came up on the pre-workshop call.

Your file stays on your laptop

Claude Code writes a program. The program opens a spreadsheet in a folder on your machine. Nothing uploads it.

That changes when you deploy. So we put a password on it before it gets a URL, in the session. The risk isn’t the AI. It’s a dashboard on the internet without a lock.

You are a financial institution, so we build like one

Dealers fall under GLBA and the FTC Safeguards Rule if you finance or lease. Penalties run to $50,120 per violation, and the FTC published its first dealer-specific FAQs in June 2025.

This dashboard needs zero customer records. Monthly counts by lead source are not customer information. Names, emails, phones and buyer-linked VINs are, and we do not use them. Two checks ship in the toolkit:

/check-my-data reads your export before we build anything and tells you if a column looks like customer information. It reports the column name, never the contents.

/check-before-deploy runs before the dashboard gets a URL: the password gate fails closed, API routes are covered, no key is exposed to the browser, no data file is committed.

The long version is in SECURITY.md. Read it on the plane.

Before you ask

Do I need to know how to code?

No. You paste prompts that are already written and decide whether you believe what comes back.

Check the results against the numbers you normally see. A source at a 400% closing ratio is yours to spot.

What does this cost?

Claude Pro, $20/month. Node and Git are free. GitHub and Vercel are optional and also free.

I am on Windows. Will this work?

Yes. Every command has a Windows form; the toggle above switches them. Claude Code runs on Windows 10 1809 and later.

Install Git for Windows. Without it Claude Code uses PowerShell and your screen stops matching mine.

What if my CRM export does not match those column names?

We map your CRM’s column names to the dashboard’s in the session.

Do not re-export or clean it up by hand. Bring it as it came out.

What if I cannot get my data in time?

Come anyway. The first eighty minutes run on the sample so every screen matches mine. Your own file is the last ten minutes, and it works the same at home.

Will this connect to my CRM live?

Not in ninety minutes. Live CRM feeds, nightly refresh and multi-rooftop permissions are real work. Putting it online is optional too: with a Vercel account it is three commands, behind a password.

You leave with a dashboard on an export you can refresh any time. NEXT-STEPS.md covers the rest.

Do I keep it afterwards?

All of it: the folder, the code, the dashboard. The formulas are written out so you can check any number on the screen.

What if I fall behind during the session?
