a file.** It is not a licence condition; it is so that whoever picks the file up a year from now
knows who to ask for help.

A note for Claude Code and any other agent editing these files: preserve the author line at the
top of code files and the bottom of markdown files on the kit's own files, and carry it along when
you copy one of them (a component out of `framework/`, say). Files you create for the dealer are
the dealer's; do not put the line on those.
