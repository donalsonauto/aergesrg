Build a dashboard on your data, in 90 minutes.  bit.ly/OhMyDash2026

HOW TO USE THIS FILE

  Copy the block under each step and paste it into Claude Code. Wait for it
  to finish and tell you what it did before you paste the next one. You do
  not have to type any of this, and you do not have to know what is in the
  folder: Claude reads it.

  After the first step, Claude lays out the build as phases and asks before
  each one. Keep going and next phase mean carry on with its plan, so two
  of the steps below really are just those words.

--------------------------------------------------------------------------
BEFORE YOU START  (Mac)

  1. Unzip the folder and put it where you keep projects.
  2. Open Terminal: press Command and Space, type Terminal, press Return.
  3. Go into the folder. Type cd, then a space, then drag the folder onto
     the Terminal window and press Return. It looks like this:

         cd ~/Projects/ohmydash

  4. Start Claude Code:

         claude --dangerously-skip-permissions --chrome --rc

  5. Later, when it tells you to run the dev server: open a SECOND Terminal
     tab (Command and T), go into the same folder, and run

         npm run dev

     Leave that tab open and keep http://localhost:3000 in your browser.

### PHASE 1

--------------------------------------------------------------------------
Launch  -  Get the toolkit. Launch Claude Code.
--------------------------------------------------------------------------

cd ~/Projects/ohmydash
claude --dangerously-skip-permissions --chrome --rc

What you should see:
  - PROMPTS-MAC.txt or PROMPTS-WINDOWS.txt in the folder: every prompt today, in order, to copy
  - bit.ly/OhMyDash2026: the folder. Unzip it, put it where you keep projects, then cd into it

  - --chrome: it can open your dashboard in the browser, click through it and check its own work
  - --rc: pick this same session up in the Claude app on your phone. The work runs on your laptop

Step 1  -  Start with a summary
--------------------------------------------------------------------------

What is this project about? Give me a summary.

What you should see:
  - A plain English summary, no code
  - It names your data files and the guidelines it found
  - It knows what you are about to build before you say it
  - Ask this of any project you ever open

--------------------------------------------------------------------------
Step 2  -  Verify the data before you build on it
--------------------------------------------------------------------------

Verify my data first.

What you should see:
  - Row count, date range, store and source counts, for both files
  - Last month's leads and sales by store: open your CRM and check them before anything gets built
  - A PII verdict, by column name only
  - A mapping from your column names to the spec names, which you can correct

### PHASE 4

--------------------------------------------------------------------------
Step 7  -  Let it loop until it is done
--------------------------------------------------------------------------

/loop review this dashboard against the guidelines, fix what you
find, and stop when a full pass finds nothing to fix

What you should see:
  - It runs a pass, fixes what it found, runs again
  - It stops on its own and tells you the pass came back clean
  - Check it on your phone while it works
  - /loop 5m check the deploy and tell me if it is down is the timed form
  - This is how you buy back your time: say the standard once, walk away
